# Data

The three public datasets are **not** redistributed in this repository. Download them from the original providers
and place the files exactly as below (see also Section 3 of the main README):

```
data/
├── pv_fault_dataset/            Lazzaretti et al. (2020) field plant
│   ├── dataset_elec.mat         https://github.com/clayton-h-costa/pv_fault_dataset
│   └── dataset_amb.mat
├── GPVS/CSV_Files/              GPVS-Faults (Bakdi et al.), https://doi.org/10.17632/n76t439f65.1
│   ├── F0L.csv … F7L.csv
│   └── F0M.csv … F7M.csv
└── TECNALIA/                    TECNALIA / Univ. of Ljubljana, https://doi.org/10.5281/zenodo.18306410 (CC BY 4.0)
    └── data_<Module>/data_<Module>.csv   (Atersa, JaSolar, Ningbo Solar, Photowatt, Trina Solar)
```

Please cite the original dataset publications when using them.
